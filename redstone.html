Redstone and Mechanics

The quirks that make engineers smile.

JAVA ONLY
Quasi-connectivity.
Pistons, droppers and dispensers can be powered by redstone sitting on the block above them, even diagonally. It's a bug Mojang kept as a feature, and half of Java redstone relies on it.
Copper bulbs have memory.
One redstone pulse turns them on and they stay on until the next pulse. It's a whole T flip-flop in a single block, and they dim as they oxidize.
Wind charges press buttons, levers and bells.
You can trigger redstone from a distance just by throwing one.
Honey blocks refuse to stick to slime blocks.
Every other block sticks to one or the other, but those two won't stick to each other — flying machine builders exploit this constantly.
Spawn chunks stay loaded forever,
even when nobody is there. That's why farms built at world spawn run around the clock.
Java and Bedrock unless noted. The piston door is Java-only (quasi-connectivity doesn't exist on Bedrock). Creaking needs Java 1.21.4+ / Bedrock 1.21.50+; happy ghasts need Java 1.21.6+ / Bedrock 1.21.90+.
